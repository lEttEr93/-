# 大学食草路 1.4：电脑与手机

## Windows 使用

将 Windows 压缩包完整解压到可写目录，双击 `CampusLife.exe` 或 `Start-CampusLife.cmd`。不能只复制 exe，程序依赖同目录的运行库。支持 Windows 10/11 x64，无需另装 Node、.NET 或 Java。

左侧直接进入课表、日程、小径、账单、月结、统计、AI 助手、我的。沿用手机业务规则与数据格式。日程在电脑上显示月历和当天列表，编辑表单居中。`Ctrl+1` 至 `Ctrl+8` 切页，`Ctrl+N` 新建日程（账单页为新记账），`Esc` 关闭表单。

第一次启动带原源码内嵌课表，账目与日程为空；手机现有数据不会凭空出现在电脑上，需要蓝牙接收或 JSON 导入。原课表可在 AI 工具中修改／导入。AI 在「我的」单独配置自己的 DeepSeek API Key；会使用 API 额度。没有 Key 时其余业务可离线使用。

关闭主窗口会继续在托盘运行。托盘右键可显示主窗口、小组件或彻底退出。小组件默认每 12 秒轮播今天课表与未来七天日程；支持暂停、鼠标悬停暂停、手动翻页、日程完成／撤销、新日程和记一笔。拖动顶部移动，拖动边缘调整大小。置顶、轮播间隔与开机启动在「设备与小组件」设置。系统开启减少动画时默认暂停轮播并减少动效。

在「我的」开启课程／日程提醒后，程序运行期间会在开始前 5 分钟内显示 Windows 通知；电脑休眠或退出应用期间不提醒。全天日程由小组件显示。原安卓常驻通知由桌面小组件承担。支付短信／通知仍由手机采集；电脑可粘贴支付消息交给 AI 核对入账。

若当前受限环境中 exe 启动后立即退出，可尝试 `Start-Compatibility.cmd`。此入口关闭 Chromium 操作系统沙箱，供兼容性排障；主入口保持沙箱开启。渲染器仍使用 contextIsolation，关闭 Node 集成。开发自动化在当前受限执行环境中使用了此兼容参数，不能视为普通用户桌面启动的验证。

## 安卓安装与原数据

提供 `campus-life-1.4-test.apk`、更新后的安卓源码，以及全项目源码。包名仍为 `com.termux.jizhang`，versionCode 5。Android 7+；Android 12+ 首次开启同步需允许「附近的设备／蓝牙连接」。

**先在旧手机应用中导出 JSON 备份并确认文件可读取。** 输入源码包没有原签名密钥，附带 APK 使用新的测试签名，不能直接覆盖原签名不同的已安装版本。推荐用原 Termux 环境的原密钥构建更新；原 `android/build.sh` 保留了原签名路径。只有确认备份可恢复后，才考虑卸载旧版安装测试版并导入。不要为解决签名冲突直接删除旧应用数据。

测试签名不是正式发布证书。交付目录 `signing/test.keystore` 仅用于日后更新本次测试版，别名 `campus-test`，密码 `android`。正式发布应改用自己的私有签名。

## 蓝牙同步

1. 在 Windows 和手机系统蓝牙设置中完成配对。现有蓝牙音频连接可继续使用，但音频协议不能承载本应用账目数据。
2. 手机新版应用进入「我的 → 电脑蓝牙同步」，开启同步并授权。**保持手机应用打开**，不要锁屏或切后台。
3. 电脑进入「设备与小组件」，刷新设备、选择手机，点击「连接手机」。已配对设备列表也可能包括耳机、手柄，应选手机。
4. 选择「手机 → 电脑」或「电脑 → 手机」，查看两端提示并确认。不要在等待确认期间修改数据或运行 AI。每次操作以所选来源端为准，接收端整份替换业务数据，**不会合并两端各自的新记录**。
5. 完成后检查账目、课表、日程。超时、拒绝或中断后可断开并重新连接。手机没有开启新版监听时，只有蓝牙音频已连接仍不能同步。

同步字段：分类、账目、固定账单、付款记录、预算、宽限期、整学期课表、日程、小径、AI 聊天历史和自定义工具。API Key、API 余额采样状态、外观、通知和设备偏好不传输。图片若保存在聊天历史中，会随聊天同步；总数据上限 7 MiB，超过时请先精简历史。

接收替换前自动备份，保留最近 30 份。电脑在 `data/backups`，普通编辑另有 `ledger.json.previous`；手机在应用私有目录，可点「复制同步前备份」取出最近一份，再通过原导入界面恢复。主动导出的完整 JSON 备份可能包含 API Key，需自行妥善保管。

## 数据位置与恢复

便携版业务数据位于程序旁 `data/ledger.json`，桌面配置为 `data/desktop.json`。移动程序时连同 `data` 一起移动；更新时保留 `data`。如有 AI_CACHES，浏览器缓存走该变量，否则在程序旁 `cache`。自定义 `CAMPUS_DATA_DIR` 可覆盖数据路径；开机启动使用当前程序路径，移动后应重新开启。

恢复前从托盘退出程序，保留整个 data 文件夹。可在「我的」导入已导出 JSON，或将所需备份复制为 `data/ledger.json` 后重启。手机、电脑都应先保留当前备份再恢复。
